FUEL RECORD HOME SCREEN WEB APP

This is an unofficial worksheet, not approved maintenance documentation.

HOSTING (one-time):
1. Upload all five web files (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) together to a static HTTPS website, keeping their filenames and folder together. GitHub Pages or Netlify can host these files. Do not upload README.txt if you do not want it public.
2. Open the resulting HTTPS URL in Safari on your iPhone.
3. Use Share > Add to Home Screen > Add. Open from the new Home Screen icon while online once.
4. Test by switching to Airplane Mode and reopening. The calculation form should load offline.

The form currently has no functioning live SQ297 registration data source. Registration stays editable and blank if no source is configured.

SECURITY: Do not enter operationally sensitive information into a publicly hosted copy. Static hosting serves the code but form inputs are not submitted by this app. Check your employer policy before using it at work.
